# Shillex Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Shillex — a chat-first social platform for Solana memecoin communities with a real multi-user backend, realtime chat, interactive contract-address mentions, and an honest, clearly-labeled demo world.

**Architecture:** npm-workspaces TypeScript monorepo. `packages/shared` holds types, validation, mint parsing and link builders used by both sides. `apps/server` is one Node process running Fastify (REST under `/api`) and Socket.IO on the same HTTP server, with Drizzle ORM over a Postgres schema (PGlite on disk locally, node-postgres when `DATABASE_URL` is set). `apps/web` is a Vite + React SPA using React Router and TanStack Query, with socket events patched into the query cache.

**Tech Stack:** Node 24 LTS, TypeScript 7.0.2 (native tsc), Fastify 5.12, Socket.IO 4.8, Drizzle ORM 0.45 + drizzle-kit 0.31, @electric-sql/pglite 0.5.8, pg 8, @node-rs/argon2 2.2, zod 4.6, bs58 6, ulidx 2.4, React 19.3, React Router 8.4.0, TanStack Query 5, Vite 8.3.4 (Rolldown), Vitest 5.0.3, Testing Library, Playwright 1.64, lucide-react. Upgraded from TS 5.9 / RR 7 / Vite 7 / Vitest 3 on 2026-10-09 at the user's request (Task 15b).

**Spec:** `docs/superpowers/specs/2026-10-09-shillex-design.md` — executors read the spec and this plan together.

## Global Constraints

- Module system: `"type": "module"` in every package; TypeScript `module`/`moduleResolution` = `NodeNext` for server/shared, `Bundler` for web.
- Pinned versions (exact): typescript 7.0.2, fastify 5.12.5, @fastify/cookie 11.1.3, @fastify/static 10.1.5, @fastify/multipart 10.1.3, @fastify/rate-limit 11.2.1, socket.io 4.8.4, socket.io-client 4.8.4, drizzle-orm 0.45.4, drizzle-kit 0.31.11, @electric-sql/pglite 0.5.8, pg 8.23.1, @node-rs/argon2 2.2.2, zod 4.6.5, bs58 6.0.0, ulidx 2.4.1, react 19.3.0, react-dom 19.3.0, react-router 8.4.0, @tanstack/react-query 5.104.1, vite 8.3.4, @vitejs/plugin-react 6.1.2, vitest 5.0.3, @testing-library/react 16.3.3, jsdom 30.1.2, @playwright/test 1.64.0, tsx 4.23.15, concurrently 10.0.6, lucide-react 1.54.0, @fontsource/inter 5.3.0, @fontsource/jetbrains-mono 5.3.0, @fontsource/space-grotesk 5.3.0.

## Review Focus

Inputs and failure modes the spec implies but no feature test naturally exercises; each has a pinned test in the owning task.

1. **Contract addresses inside punctuation, URLs and markup** — `CA: <mint>.`, `(<mint>)`, `<mint>,<mint>` should each yield chips; a mint inside a pasted URL (`https://dexscreener.com/solana/<mint>`) must stay part of the link and not become a chip; a 44-char base58 string that decodes to 33 bytes must not match. → Task 1 (`mint.test.ts`, "punctuation and URLs").
2. **Hostile or odd Dexscreener/RPC responses** — empty array, pairs where the mint is only the quote token, missing `liquidity`, HTTP 429, malformed JSON, RPC timeout. Expected: never invent data; `unindexed` for no base pairs, `error` (retryable after 60 s) for 429/timeout/garbage. → Task 11 (`resolver.test.ts`, "hostile upstream").
3. **Whitespace-only, emoji-heavy and boundary-length bodies** — `"   \n "` rejected with 400 `EMPTY_BODY`; a 1000-emoji post accepted (code points, not UTF-16 units); 1001 rejected. → Task 6 (`posts.test.ts`, "body boundaries").
4. **Removed/banned members with live sockets** — after a mod bans a user or a user leaves a group, their open sockets must stop receiving that room's events immediately. → Task 12 (`realtime.test.ts`, "eviction").
5. **Blocks across every interaction path** — a blocked user cannot reply to, quote, repost, react to, mention-notify, follow or DM the blocker, and neither sees the other in feeds or suggestions. → Task 7 (`blocks.test.ts`).
